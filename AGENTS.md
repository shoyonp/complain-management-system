- UI/UX Pro Max: Use for design systems, typography, color palettes, spacing, and visual consistency.
- Frontend Design: Use when designing new pages, layouts, dashboards, and polished user interfaces.
- Hallmark: Use when visual refinement or additional UI polish is needed.

- Frontend Engineering: Use when working on architecture, maintainability, refactoring, and frontend code quality.

# Skill Usage Rules

- Inspect available skills and their descriptions before selecting one.
- Select only the skills relevant to the current task.
- Do not load every installed skill for every task.
- Avoid combining skills that provide conflicting or repetitive instructions.
- Follow the selected skill's actual instructions.
- Do not install additional skills unless explicitly requested or approved.
- Maintain a consistent design system across all pages and components.

# UI Quality

- Prioritize clean, modern, professional, and user-friendly interfaces.
- Ensure responsive layouts across mobile, tablet, and desktop.
- Maintain consistent typography, spacing, colors, and component styles.
- Provide proper loading, empty, error, and success states.
- Prioritize accessibility and intuitive navigation.
- Avoid unnecessary visual complexity and decorative elements.

# Project rules

- Stack: React+Vite, Tailwind, shadcn/ui, React Router, Axios, TanStack Query; Node, Express, MongoDB; Firebase Auth. Plain JavaScript, no TypeScript.
- Do not add Python, FastAPI or ML code. AI is only the provider interface (Section 12).
- Follow the folder structure in Sections 4 and 5.
- Never store student identity in complaints (Section 8). Use role-based serializers.
- Work on ONE milestone at a time. Ask before adding libraries not listed in Section 1.8.
- Write tests for authorization and privacy rules.

# Final Rule:

Follow docs/BLUEPRINT.md and this AGENTS.md consistently. When a task conflicts with either document, stop and ask for clarification instead of making an independent architectural decision.
